# AirScope

SDR 受信機のモニター画面を再現した **操作シミュレーター（デモ）** です。

- 公開ページ: https://yokomizomasaharu-sketch.github.io/airscope/
- 実電波の受信は行いません。周波数・局・通話・スペクトラム・音声はすべてブラウザ内で生成した架空のデータです。
- SDR 機器・アンテナには接続していません。画面上の ID・組織名・信号値もすべてサンプルです。

## 主な機能

- **プリセット（バンド／局リスト）切替** — 左ペイン上部のドロップダウンでワンクリック切替
  - 標準デモ（273MHz STD-T79）／南海電鉄（149.85 MHz 周辺）／JR 鉄道無線（352MHz 帯）
  - 日本主要空港のエアバンド（KIX・ITM・HND・NRT・FUK、AM モード）
  - 海外空港（台北松山 RCSS・香港 VHHH・マニラ RPLL）— LiveATC.net の公開ページへのリンク付き
- 周波数入力（Enter / 聴く）・ステップ切替（自動 12.5k / 6.25k / 12.5k / 25k）
- 局一覧（フィルタ：すべて / 通話中 / グループ、お気に入り、複数選択）
- 受信範囲の自動探索・通話の始まった局への自動切替
- モニターパネル（信号 / SNR / 同期率 / 符号器、TDMA 4スロット、音声レベルとスケルチ閾値、録音カウンター）
- 空港プリセットでは TDMA スロット表示が AM の受信状態（搬送波 / スケルチ / 変調 / 音声）に自動で切り替わる
- 帯域スペクトラム（Canvas 描画。クリックでチューニング、ドラッグで帯域移動、ホイールで1ステップ）
- 通話・録音履歴、設定（デモ速度 / スケルチ閾値 / Web Audio のデモ音）
- 規格の強制切替（STD-T79 / DMR / NXDN / アナログFM / AM (エアバンド)）
- PWA（iPhone / iPad の「ホーム画面に追加」に対応、noindex）

## 周波数データについて

南海・JR・空港の周波数は、AIP Japan（国土交通省航空局）・LiveATC.net の公開ページ・公開周波数リストで確認した**掲載値**です。実際の電波は受信せず、受信・復調・通話・スペクトラムはすべてブラウザ内のシミュレーションです。画面内の「デモ表示」バッジと各プリセットの注記にその旨を明記しています。

- 空港の周波数は AIP の掲載値（例：KIX Tower 118.200 / Ground 121.600 / ATIS 127.850）
- LiveATC のリンクは、公開フィードが実在する空港（RJTT / RJAA / RJOO / RJFF / RCSS / VHHH / RPLL）のみに設定
- 台北桃園（RCTP）・ソウル仁川（RKSI）・関西国際（RJBB）には LiveATC の公開フィードがないため、リンクは置いていない
