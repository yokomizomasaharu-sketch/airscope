# AirScope

SDR 受信機のモニター画面を再現した **操作シミュレーター（デモ）** です。

- 公開ページ: https://yokomizomasaharu-sketch.github.io/airscope/
- 実電波の受信は行いません。周波数・局・通話・スペクトラム・音声はすべてブラウザ内で生成した架空のデータです。
- SDR 機器・アンテナには接続していません。画面上の ID・組織名・信号値もすべてサンプルです。

## 主な機能

- 周波数入力（Enter / 聴く）・ステップ切替（自動 12.5k / 6.25k / 12.5k / 25k）
- 局一覧（11局のサンプル、フィルタ：すべて / 通話中 / グループ、お気に入り、複数選択）
- 受信範囲の自動探索・通話の始まった局への自動切替
- モニターパネル（信号 / SNR / 同期率 / 符号器、TDMA 4スロット、音声レベルとスケルチ閾値、録音カウンター）
- 帯域スペクトラム（Canvas 描画。クリックでチューニング、ドラッグで帯域移動、ホイールで1ステップ）
- 通話・録音履歴、設定（デモ速度 / スケルチ閾値 / Web Audio のデモ音）
- 規格の強制切替（STD-T79 / DMR / NXDN / アナログFM）
- PWA（iPhone / iPad の「ホーム画面に追加」に対応、noindex）
