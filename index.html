Mac RTL-SDR 接続ガイド

  1. RTL-SDR ドングル（RTL-SDR Blog V4 など）を Mac の USB に挿します。
  2. ターミナルで下のセットアップを実行します（初回のみ）。
  3. start_airscope_sdr.sh を実行し、ws://127.0.0.1:8765 で待ち受けます。
  4. AirScope の「受信ソース」→「Mac RTL-SDR」→「接続」でつながります。

このモードは Mac のブラウザで AirScope を開いて使います（127.0.0.1 は Mac 自身を指すため、iPhone からは接続できません）。https のページから ws://127.0.0.1 への接続は、Chrome / Safari ではローカル接続として許可されます。

brew install librtlsdr
cd mac-sdr-bridge
python3 -m venv .venv && . .venv/bin/activate
pip install websockets numpy pyrtlsdr
./start_airscope_sdr.sh
# ドングルなしで接続テスト（合成信号）
python3 bridge.py --selftest
受信できるもの／できないもの AM（エアバンド 118–137MHz）と FM（鉄道・私鉄 150/352MHz帯など）のアナログ音声です。TDMA・DMR・NXDN などのデジタル変調や暗号化された業務無線は復調できません（音声にはなりません）。受信のみで送信はしません。
電波法にもとづき、傍受した通信の内容を他人に知らせたり、自分のために使用したりすることはできません。受信した音声は個人の趣味の範囲で扱ってください。
